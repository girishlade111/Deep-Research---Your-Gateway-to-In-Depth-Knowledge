# Deep Research — Your Gateway to In-Depth Knowledge

A single-page marketing/landing website for a "Deep Research" product — an in-depth research/knowledge tool. Built as one self-contained `index.html` with Tailwind CSS styling: hero headline ("Uncover the World's Depths"), feature sections, and call-to-action blocks.

## Features

- Responsive landing page (Tailwind utility classes)
- Hero section with headline and CTA
- Feature/value-prop sections
- SVG icons and decorative graphics, no external image dependencies
- Vanilla JavaScript (a few inline `<script>` blocks)

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript

## Quick Start

No build step — just open or serve `index.html`:

```bash
# open directly
open index.html

# or serve locally
python3 -m http.server 8000
```
